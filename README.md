# ABC Shopping - E-Commerce Web Application

A full-stack e-commerce web platform built using Java Servlets and WebLogic Server for online shopping, user authentication, and product browsing.

## 🛠️ Tech Stack
- **Backend / Controller:** Core Java Servlets
- **Frontend / View:** HTML5, CSS3, JavaScript
- **Application Server:** Oracle WebLogic Server
- **Database:** Oracle Database

## ✨ Features
- User Registration & Authentication (Login / Sign Up)
- Product Categories (Mobiles, Laptops, Watches, Cars, Men's & Women's Fashion)
- Dynamic Product Listing & Browsing
- Shopping Cart & Order Management

## ⚙️ Prerequisites & Setup
1. Installed **Java Development Kit (JDK)**
2. Configured **Oracle WebLogic Server**
3. Database connection setup with **Oracle Database**
4. Deploy the project folder to WebLogic application deployment directory and start the server.
5. Open browser and access: `http://localhost:7002/Shoping_Site_By_Servlet/index.html`
